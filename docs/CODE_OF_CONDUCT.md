# Code Of Conduct

Verenu welcomes direct, technical, honest discussion. Keep it useful.

## Expected Behavior

- Be clear about facts, assumptions, and tradeoffs.
- Critique code, design, docs, and decisions without attacking people.
- Respect privacy. Do not post another person's private text, API keys, contact details, logs, screenshots, or local paths.
- Keep security-sensitive details out of public issues until a maintainer has a private reporting path.

## Unacceptable Behavior

- Harassment, threats, stalking, or sustained personal attacks.
- Publishing private information without explicit permission.
- Posting secrets, API keys, exploit details, or private user data.
- Derailing issue threads with unrelated arguments.
- Spam or low-effort automation noise.

## Enforcement

Maintainers may edit, hide, delete, lock, or report content that violates this code. Contributors who repeatedly ignore it may be blocked from participating in the project.

## Scope

This applies to repository issues, pull requests, discussions, review comments, release threads, and any other official Verenu project space.
