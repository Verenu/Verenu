# Support

Use GitHub Issues for bugs, troubleshooting, and feature requests, or email [support@verenu.com](mailto:support@verenu.com) if you'd rather not post publicly.

Before opening an issue:

- Check [Troubleshooting](TROUBLESHOOTING.md).
- Check [Install Verenu](INSTALL.md) for install warnings and platform notes.
- Check [Data And Privacy](DATA_AND_PRIVACY.md) if the issue involves storage, logs, providers, exports, or network calls.

## What To Include

- Verenu version.
- Operating system and version.
- Provider and model names, if relevant.
- Clear reproduction steps.
- What you expected to happen.
- What actually happened.
- Any test command you ran.

## What Not To Include

Do not post:

- API keys.
- Private dictated text.
- Email addresses, names, or account identifiers.
- Screenshots with private text.
- Full local file paths.
- Logs containing secrets, clipboard contents, prompts, dictionary terms, snippet bodies, or transcripts.

Use fake sample text when you need to explain a dictation problem.
